# Common personal-name lexicon (Decision C, round-4 security re-audit).
#
# Purpose: `reject_reason_for_skill_name`'s person-name-shape reject is a
# THREE-way conjunction (name-SHAPED and vocab-miss and hits this lexicon,
# OR a non-Latin script), not a strict allowlist. Shape alone cannot tell
# "distributed systems" apart from "Casey Rivera" -- both are two
# Title-Case-able alphabetic tokens with no technical marker outside the
# 220-term skill vocabulary. This file supplies the missing signal: a
# common given-name / surname lookup, so a name-shaped, vocab-miss
# candidate is only rejected as a PERSON's name when at least one of its
# real tokens is actually a common personal name.
#
# Format: one lower-cased name per line (given names and surnames mixed --
# the reject check does not need to know which slot a hit came from, only
# THAT a token hit). Blank lines and lines starting with '#' are ignored.
# Loaded once (`_name_lexicon`, lru_cache) into a frozenset.
#
# Provenance / licence: hand-curated in-repo from PUBLIC-DOMAIN frequency
# knowledge -- the shape of the U.S. Census Bureau's decennial surname
# frequency tables and the U.S. Social Security Administration's popular
# baby-name rankings, both U.S. government works and not subject to
# copyright (17 U.S.C. S 105) -- supplemented with a broader hand-added set
# of common given names/surnames from outside Anglo-American naming
# conventions (East Asian, South Asian, Slavic, Arabic, Romance-language,
# Irish/Scottish, Germanic/Dutch) so the lexicon is not Anglo-only, per
# Decision A/S4's disparate-impact finding. NO network fetch, no cloud
# lookup, at build time or runtime -- this list ships in the repo, offline,
# exactly like `aliases.yaml`/`categories.yaml` beside it.
#
# Size: ~780 unique entries (some given-name/surname duplicates across
# lines collapse into the same set at load time -- lru_cache-loaded into a
# frozenset, so a duplicate line costs nothing but is not "double-counted").
# Small by design -- a lookup table this size loads and
# checks in microseconds, and the module's OWN recall guard
# (`test_pipeline_skills_graph.py`) already proves the skill vocabulary is
# not shadowed by it. See the module docstring's "Round-4" section for the
# accepted residuals this file does NOT try to solve (non-Latin-script
# names; a real "Kafka"/"Django" surname, which the vocabulary arm of the
# conjunction always wins over regardless of this file's contents).
